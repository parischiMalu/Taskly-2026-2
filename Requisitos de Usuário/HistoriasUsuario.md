# 1. História de Usuário

<p align="justify">A Tabela 2 a seguir contém as Histórias de Usuários elicitadas.</p>

| ID | História de Usuário | Critérios de aceitação | Prioridade | RF/RNF relacionado | Story Points |
| :--: | :-- | :-- | :--: | :--: | :--: |
| <span id="ustory-01"></span> US01 | Como usuário, quero realizar meu cadastro no sistema informando e-mail, nome e senha, para criar minha conta. | 1. O sistema deve disponibilizar uma opção para realizar o cadastro.<br>2. O sistema deve permitir que o usuário informe e-mail, nome e senha.<br>3. O sistema deve permitir concluir o cadastro após o preenchimento dos dados necessários. | Alta | RF01 | 2 |
| <span id="ustory-02"></span> US02 | Como usuário, quero realizar login no sistema, para acessar minhas informações e funcionalidades pessoais. | 1. O sistema deve disponibilizar uma opção para realizar login.<br>2. O sistema deve permitir que o usuário informe e-mail e senha.<br>3. O sistema deve permitir o acesso às funcionalidades pessoais após o login. | Alta | RF02 | 2 |
| <span id="ustory-03"></span> US03 | Como usuário, quero acessar minhas informações pessoais cadastradas, para consultar meus dados no aplicativo. | 1. O sistema deve disponibilizar uma opção para acessar as informações pessoais.<br>2. O sistema deve apresentar as informações pessoais cadastradas pelo usuário. | Média | RF03 | 2 |
| <span id="ustory-04"></span> US04 | Como usuário, quero gerenciar minhas informações pessoais cadastradas, para manter meus dados atualizados no aplicativo. | 1. O sistema deve permitir que o usuário altere suas próprias informações pessoais cadastradas. | Média | RF03 | 3 |
| <span id="ustory-05"></span> US05 | Como usuário, quero criar tarefas em uma lista, para organizar minhas atividades e compromissos. | 1. O sistema deve permitir que o usuário crie uma nova tarefa.<br>2. O sistema deve adicionar a tarefa criada à lista de tarefas.<br>3. O sistema deve apresentar a tarefa criada na lista. | Alta | RF04 | 5 |
| <span id="ustory-06"></span> US06 | Como usuário, quero visualizar, editar e excluir minhas tarefas, para manter minha lista de atividades organizada e atualizada. | 1. O sistema deve permitir que o usuário visualize suas tarefas cadastradas.<br>2. O sistema deve permitir que o usuário edite uma tarefa cadastrada.<br>3. O sistema deve permitir que o usuário exclua uma tarefa cadastrada. | Alta | RF04 | 5 |
| <span id="ustory-07"></span> US07 | Como usuário, quero marcar uma tarefa como concluída, para acompanhar as atividades que já realizei. | 1. O sistema deve permitir que o usuário marque uma tarefa como concluída.<br>2. O sistema deve permitir identificar quais tarefas foram concluídas. | Alta | RF04 | 3 |
| <span id="ustory-08"></span> US08 | Como usuário, quero criar anotações, para registrar conteúdos de aulas, lembretes, ideias e outras informações relevantes. | 1. O sistema deve permitir que o usuário crie uma nova anotação.<br>2. O sistema deve registrar o conteúdo informado pelo usuário.<br>3. O sistema deve disponibilizar a anotação criada para consulta. | Alta | RF05 | 3 |
| <span id="ustory-09"></span> US09 | Como usuário, quero visualizar, editar e excluir minhas anotações, para manter minhas informações organizadas e atualizadas. | 1. O sistema deve permitir que o usuário visualize suas anotações cadastradas.<br>2. O sistema deve permitir que o usuário edite uma anotação cadastrada.<br>3. O sistema deve permitir que o usuário exclua uma anotação cadastrada. | Alta | RF05 | 5 |
| <span id="ustory-10"></span> US10 | Como usuário, quero criar eventos no calendário informando nome, data, horário e descrição, para organizar meus compromissos e atividades. | 1. O sistema deve permitir que o usuário crie um novo evento.<br>2. O sistema deve permitir que o usuário informe o nome do evento.<br>3. O sistema deve permitir que o usuário informe a data do evento.<br>4. O sistema deve permitir que o usuário informe o horário do evento.<br>5. O sistema deve permitir que o usuário informe uma descrição para o evento.<br>6. O sistema deve apresentar o evento criado no calendário. | Alta | RF06 | 5 |
| <span id="ustory-11"></span> US11 | Como usuário, quero visualizar, editar e excluir meus eventos, para manter meu calendário organizado e atualizado. | 1. O sistema deve permitir que o usuário visualize seus eventos no calendário.<br>2. O sistema deve permitir que o usuário edite um evento cadastrado.<br>3. O sistema deve permitir que o usuário exclua um evento cadastrado. | Alta | RF06 | 3 |
| <span id="ustory-12"></span> US12 | Como usuário, quero configurar lembretes para meus eventos, para ser notificado no momento que eu definir antes do evento. | 1. O sistema deve permitir que o usuário configure um lembrete para um evento cadastrado.<br>2. O sistema deve permitir que o usuário selecione o momento em que deseja ser notificado antes do evento.<br>3. O sistema deve registrar a configuração do lembrete para o evento. | Alta | RF07 | 3 |
| <span id="ustory-13"></span> US13 | Como usuário, quero receber notificações dos meus eventos no momento configurado, para ser lembrado dos meus compromissos. | 1. O sistema deve enviar a notificação no momento configurado pelo usuário, não ultrapassando 1 minuto após o horário definido.<br>2. A notificação deve estar relacionada ao evento correspondente.<br>3. A notificação deve apresentar informações que permitam identificar o evento, como nome e horário. | Alta | RF08, RNF07 | 3 |
| <span id="ustory-14"></span> US14 | Como usuário, quero cadastrar hábitos informando seu nome e, opcionalmente, uma descrição, para registrar atividades que desejo realizar de forma recorrente. | 1. O sistema deve permitir que o usuário cadastre um novo hábito.<br>2. O sistema deve exigir que o usuário informe o nome do hábito.<br>3. O sistema deve permitir que o usuário informe uma descrição opcional para o hábito.<br>4. O sistema deve disponibilizar o hábito cadastrado para configuração de recorrência. | Alta | RF09 | 5 |
| <span id="ustory-15"></span> US15 | Como usuário, quero configurar a recorrência dos meus hábitos, para definir quando desejo realizá-los. | 1. O sistema deve permitir configurar o hábito com frequência diária ou semanal.<br>2. O sistema deve permitir informar o horário de realização do hábito.<br>3. Quando a frequência for semanal, o sistema deve permitir selecionar o dia da semana.<br>4. O sistema deve registrar as configurações de recorrência definidas para o hábito. | Alta | RF10 | 5 |
| <span id="ustory-16"></span> US16 | Como usuário, quero visualizar meus hábitos cadastrados e suas configurações de recorrência, para acompanhar os hábitos que fazem parte da minha rotina. | 1. O sistema deve apresentar os hábitos cadastrados pelo usuário.<br>2. O sistema deve apresentar a frequência configurada para cada hábito.<br>3. O sistema deve apresentar o horário configurado para cada hábito.<br>4. Quando a frequência for semanal, o sistema deve apresentar o dia da semana configurado. | Média | RF11 | 2 |
| <span id="ustory-17"></span> US17 | Como usuário, quero receber notificações para meus hábitos, para ser lembrado de realizá-los. | 1. O sistema deve permitir que o usuário ative as notificações para um hábito cadastrado.<br>2. O sistema deve enviar a notificação no máximo 1 minuto após o horário definido para o hábito.<br>3. A notificação deve permitir identificar o hábito relacionado. | Média | RF12, RNF07 | 3 |
| <span id="ustory-18"></span> US18 | Como usuário, quero receber sugestões de hábitos, para encontrar opções que possa adicionar à minha rotina. | 1. O sistema deve disponibilizar sugestões de hábitos ao usuário.<br>2. O sistema deve permitir que o usuário adicione uma sugestão de hábito à sua rotina. | Baixa | RF13 | 2 |
| <span id="ustory-19"></span> US19 | Como usuário, quero criar metas de médio ou longo prazo relacionadas aos estudos ou a objetivos pessoais, para acompanhar objetivos que desejo alcançar. | 1. O sistema deve permitir que o usuário crie uma nova meta.<br>2. O sistema deve exigir que o usuário informe um nome para a meta.<br>3. O sistema deve permitir que a meta esteja relacionada aos estudos ou a um objetivo pessoal. | Alta | RF14 | 3 |
| <span id="ustory-20"></span> US20 | Como usuário, quero criar etapas para minhas metas, para dividir meus objetivos em partes menores e acompanhar sua realização. | 1. O sistema deve permitir que o usuário crie uma ou mais etapas para uma meta.<br>2. O sistema deve exigir que o usuário informe o nome da etapa.<br>3. O sistema deve permitir que o usuário informe uma descrição opcional para a etapa.<br>4. O sistema deve permitir que o usuário informe um prazo opcional para a etapa.<br>5. O sistema deve associar cada etapa à sua respectiva meta. | Alta | RF15 | 3 |
| <span id="ustory-21"></span> US21 | Como usuário, quero acompanhar o progresso das minhas metas por meio das etapas concluídas, para visualizar meu desenvolvimento em relação aos objetivos estabelecidos. | 1. O sistema deve permitir que o usuário marque uma etapa como concluída.<br>2. O sistema deve permitir que uma etapa permaneça como não concluída.<br>3. O sistema deve apresentar o progresso da meta com base na quantidade de etapas concluídas.<br>4. O sistema deve considerar a meta concluída quando todas as suas etapas forem marcadas como concluídas. | Alta | RF16 | 2 |
| <span id="ustory-22"></span> US22 | Como usuário, quero utilizar e configurar o temporizador para minhas sessões de estudo, para organizar meus períodos de concentração e descanso. | 1. O sistema deve apresentar, como configuração padrão, 25 minutos de estudo e 5 minutos de descanso.<br>2. O sistema deve permitir que o usuário altere o tempo de estudo e de descanso.<br>3. O sistema deve permitir que o usuário inicie e pause o temporizador.<br>4. O sistema deve permitir que o usuário retome uma sessão pausada.<br>5. O sistema deve permitir que o usuário cancele uma sessão em andamento. | Alta | RF17 | 3 |
| <span id="ustory-23"></span> US23 | Como usuário, quero que o tempo das minhas sessões de estudo seja registrado pelo aplicativo, para manter um registro do tempo utilizado nos estudos. | 1. O sistema deve registrar o tempo utilizado em uma sessão de estudo realizada por meio do temporizador.<br>2. O sistema não deve registrar uma sessão que tenha sido cancelada.<br>3. O sistema deve disponibilizar os registros das sessões para consulta no histórico de estudos. | Média | RF18 | 3 |
| <span id="ustory-24"></span> US24 | Como usuário, quero consultar as informações registradas sobre minhas sessões de estudo, para acompanhar meu histórico de estudos. | 1. O sistema deve permitir que o usuário consulte suas sessões de estudo registradas.<br>2. O sistema deve apresentar as informações registradas sobre as sessões de estudo. | Média | RF19 | 2 |

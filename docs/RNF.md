# 1. Requisitos Não Funcionais

<p align="justify">A <i>Tabela 1</i> a seguir contém os <b>Requisitos Não Funcionais (RNF)</b> elicitados utizando a técnica de Brainstorm .</p>

| ID   |                                 Requisito NF                              | Categoria/Tipo | Prioridade | Requisitos Relacionados |
| :--: | :-----------------------------------------------------------------------: |:-------------: | :--------: | :-----------------: |
| RNF01 | O usuário deve ser capaz de consultar sua rotina do dia em até 3 cliques. | Produto/Usabilidade | Média | - |
| RNF02 | O executável do sistema não deve ser superior a 1 Mbyte. | Produto/Eficiência | Alta | - |
| RNF03 | O tempo de resposta não deve exceder 3 segundos. | Produto/Eficiência | Alta | - |
| RNF04 | O usuário deve ser capaz de consultar sua rotina de outros dias do mês em até 7 cliques. | Produto/Usabilidade | Média | - |
| RNF05 | O sitema não deve exibir dados pessoais a perfis não autorizados. | Externos/Éticos | Alta | RF02, RNF06 |
| RNF06 | O sistema deve armazenar e gerenciar os dados do usuário conforme a Lei Geral de Proteção de Dados. | Externos/Legais  | Alta | RF01, RF02, RF03 |
| RNF07 | O sistema deve enviar as notificações de lembrete até 1 minuto após o horário definido. | Produto/Eficiência | Alta | RF07, RF08 |
| RNF08 | O sistema deve permitir o uso e a consulta de tarefas, notas e hábitos já salvos mesmo quando o dispositivo estiver sem conexão com a internet (Modo Offline). | Produto/Disponibilidade | Média | - |
